## Get It

Download the latest build from **[Releases](../../releases)**.

| Platform | Recommended File | Status |
|---|---|---|
| Windows | `opto-downloader-*-windows-setup.exe` | Tested and working |
| macOS | `opto-downloader-*-macos.dmg` | Tested and working |
| Linux | `opto-downloader-*-linux.AppImage` | Experimental, not fully tested |
| Manual | `opto-downloader-*-*.zip` | For advanced/manual setup |

### macOS Quarantine

If macOS blocks the app:

```bash
xattr -dr com.apple.quarantine "/Applications/OPTO Downloader.app"
open "/Applications/OPTO Downloader.app"
```

### Linux AppImage

```bash
chmod +x opto-downloader-*.AppImage
./opto-downloader-*.AppImage
```

The AppImage is generated by the release workflow, but it has not been validated like the Windows `.exe` and macOS `.dmg`.

## First Run

1. Open the app.
2. Go to **Estado** and check `ffmpeg`, `ffprobe` and `mp4decrypt`.
3. Add your personal `.wvd` file to `secrets/` or `~/.wvd/`.
4. Set language, output folder and default quality in **Preferências**.
5. Use **Episódio** or **Série**.

> The app does not include credentials, `.wvd` files, private keys or downloaded content.

## What It Does

| Area | Experience |
|---|---|
| Episode | Analyze a URL/UUID, pick quality, download or play temporarily |
| Series | Load seasons from the OPTO API and select full seasons or specific episodes |
| Downloads | Queue view with progress, grouped by series and season |
| Player | Temporary playback without saving a final MP4 to your downloads folder |
| Status | Tool checks and `.wvd` generation from `private_key.pem` + `client_id.bin` |
| CLI | Scriptable episode and series tools for advanced workflows |

## Widevine `.wvd`

A `.wvd` file is required for protected content.

The app searches:

```text
secrets/
~/.wvd/
legacy app folders
```

Never publish or share:

```text
.wvd
private_key.pem
client_id.bin
keys
tokens
downloaded media
```

## Manual ZIP Setup

Use this only if you downloaded a ZIP instead of an installer.

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 instalar_dependencias.py
python3 opto_app.py
```

Windows:

```powershell
python -m venv .venv
.\.venv\Scripts\activate
python instalar_dependencias.py
python opto_app.py
```

Platform helper scripts are available in `platform/`.

## CLI

```bash
# List series episodes
python3 opto_api_scraper.py "https://opto.sic.pt/series/name/UUID" --json

# Resolve an episode
python3 opto_api_media_resolver.py "URL_OR_UUID" --json

# Test Widevine keys
python3 opto_api_media_resolver.py "URL_OR_UUID" --test-keys --json

# Download from CLI
python3 opto_api_media_resolver.py "URL_OR_UUID" --download --quality 720
```
